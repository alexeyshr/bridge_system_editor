# 011: Space-Scoped Content and System Integration

This feature stream integrates system authoring and content publishing into the main portal using a single `Space` governance model.

## Scope

- Space model (`personal`, `team`) with visibility and membership policies
- Content model and lifecycle (`draft`, `published`, `archived`)
- Strict visibility enforcement (`hidden` spaces cannot publish public content)
- Owner-only system publish policy
- Optional tournament binding workflow (organizer-focused)
