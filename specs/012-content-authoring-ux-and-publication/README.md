# 012: Content Authoring UX and Publication Workflow

This feature stream delivers end-to-end authoring UX for portal content inside spaces.

## Scope

- Content workspace screens: list/create/edit/view
- Block-based draft editor for supported block types
- Draft save, publish, archive flows in UI
- Space-aware permissions and visibility guardrails in UX
- Discovery integration in dashboard/search/navigation
